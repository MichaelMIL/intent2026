# INTENT 2026 badge — project guide for Claude

RP2040 conference badge for the INTENT 2026 security summit. 56 × 100 mm, 2-layer, purple mask,
vending-machine outline, plus three **breakaway modules** (IR receiver, audio jack, speaker) hanging under the
pedestal on mouse-bite tabs (blank 56 × 118 mm). Each module has a 1×3 pin header (P1–P3) and plugs into a
1×3 socket on the main board (J5 IR / J6 AUDIO / J7 SPK; pin 1 GND, 2 3V3, 3 signal). Fab: JLCPCB (10-board
prototype, then 600). Board rev 0.5 (2026-10-11).

## Source of truth

The `.kicad_sch` / `.kicad_pcb` files are **generated**. Do not hand-edit them for design changes:

- Netlist: `03-kicad/scripts/design.py` (parts, pins, nets, LCSC numbers, DNP flags)
- Schematic drawing: `03-kicad/scripts/gen_sch.py` (block layout, wires, labels) on top of `schlib.py`
  (symbol placement with verified rotation/mirror transforms, wires, auto junctions, power symbols).
  After any change run `python3 scripts/check_sch.py --erc` (must print 0 problems, ERC 0 errors) and
  `python3 scripts/render_sch.py out.png [dpi] [x0 y0 x1 y1]` to look at it.
- Placement: `03-kicad/scripts/placement.py` (x, y, rot, side; mm from top-left of the 56 × 100 box).
  `MODULES` = breakaway module rectangles + tab x; `MP` = module parts in module-local mm (converted at import).
  Module nets are prefixed IRM_/AUM_/SPM_ and must never touch a main-board part (no copper crosses a tab);
  `design.MODULES` maps module → ground net / socket / header.
- Silkscreen art: `scripts/silk.py`, logo via `scripts/art_logo.py`
- Project rules / netclasses: `scripts/gen_pro.py`
- 3D models: `scripts/gen_3d.py` → `intent.3dshapes/*.wrl` (simplified boxes/cylinders for the custom footprints and
  for TS-1187A / WS2812B-2020 / MSK12C02, whose STEP files KiCad 10 does not ship). `pcb_build.py` attaches them;
  `add_3d.py <board>` does the same on an existing board.
- Custom footprints: `scripts/gen_fp.py` → `intent.pretty/` (incl. the MLT-8530 transducer and the board-only
  `MouseBites_1x4_D0.5_P1.0` footprint that `pcb_build.py` places as MB1–MB3; those are not in the schematic)
- Board outline incl. tabs and modules: `pcb_build.py` (`OUTLINE` = badge, `bottom_detour()` adds the modules);
  `outline_points(with_modules=False)` is the badge-only polygon used for the main GND pour and silk.
  `pcb_finish.py` pours GND on the badge and a separate pour per module on its own ground net.
- Routes: `build/routes.json` (router output; regenerated by `router/route2.py` with the env settings in
  BUILD-NOTES; `router/fixed_routes.json` = hand-placed GND copper the router must keep, `router/gnd_final.py` =
  GND-only re-route when a run ends with residual GND conflicts)

Small, local fixes (nudge a track, add a silk label, change a text) may be made directly on the
`.kicad_pcb` through the pcbnew Python API, but note them in BUILD-NOTES so a later regeneration
does not silently drop them.

**Full rebuild on this Mac (done 2026-10-11 for rev 0.5):** copy `03-kicad` to a scratch dir, set `W` to it, run
`build_prep.sh`, then the router with the settings in BUILD-NOTES (`ROUTE_STATE=$W/route_state.pkl` lets it
resume), then `build_finish.sh`, `fab_export.py` and the `kicad-cli pcb export gerbers/drill` commands in
BUILD-NOTES. Copy the results back only when DRC is clean, because KiCad may have the project open.
KiCad 10 saves/writes the board in the v10 file format.

Typical checks:

```bash
cd "/Users/michael/Downloads/AI PCB /03-kicad"
"$KCLI" sch erc -o /tmp/erc.rpt intent-2026-badge.kicad_sch
"$KCLI" pcb drc --schematic-parity --severity-all -o /tmp/drc.rpt intent-2026-badge.kicad_pcb
```

Under KiCad 10 the DRC parity check also reports ~74 `footprint_symbol_field_mismatch` warnings
(Description field empty on the PCB, set in the schematic). These are cosmetic and new in v10;
the KiCad 9 run was clean. ERC under v10 adds 2 `lib_symbol_mismatch` warnings (JP1, J1), also cosmetic.

## Editing while KiCad is open

KiCad does not auto-reload. If Claude rewrites a `.kicad_pcb` / `.kicad_sch` while it is open in
the GUI, the user must **File → Revert** (or close and reopen) before continuing, and must not save
over it from the GUI. Prefer: close the editor, run the script, reopen.

Open the project: `open -a KiCad "/Users/michael/Downloads/AI PCB /03-kicad/intent-2026-badge.kicad_pro"`

## Open items before ordering

0. Decide whether JLC populates the six 1×3 headers (J5–J7, P1–P3; THT hand-solder fee) or they ship DNP with loose headers. Default in the files: populated.
1. JLC upload preview: check rotations of D1–D5, D6, D7, Q1, Q2, U2, U3, U4, U5, LS1 (corrections already in CPL, see `04-fab/cpl_rotation_report.txt`). 1N4148W C81598 showed only 300 in LCSC stock on 2026-10-11.
2. Crystal C133334 wants CL = 20 pF; C11/C12 are 15 pF. ≈ +50 ppm, acceptable for USB. Swap to 27–33 pF if exactness matters.
3. Battery box supplier (wired 3×AAA, with switch, JST-PH 2.0 plug). Verify plug polarity against J3 silk.
4. QR code for the back silk once the repo URL exists (silk only, no re-layout).
5. Logo permission (Palo Alto Networks wordmark).

## Conventions

- Keypad: A = GPIO4 (SW2, top), B = GPIO3, C = GPIO2 (SW4, bottom).
- IR receiver U5 pinout: 1, 2 = GND, 3 = OUT, 4 = VCC. U5 lives on the IR module (nets IRM_*).
- Expansion slots: J5 IR = GPIO22, J6 AUDIO = GPIO11, J7 SPK = GPIO25 (GPIO25 is also J2 pin 15). Pin 1 = GND (square pad), 2 = 3V3, 3 = signal on every port.
- Mouse bites MB1–MB3 are board-only footprints (`SetBoardOnly`), excluded from BOM/CPL and from schematic parity.
- J3 is on the FRONT pedestal so assembly stays top-side only. SW5 (DNP) + JP1 are on the back.
- All refdes are on the Fab layer, not silk.
- Hebrew mirror of the BOM deltas exists (`00-bom/bom-deltas-he.md`); keep it in sync if deltas change.
